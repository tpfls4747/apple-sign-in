# 탈퇴 후 재가입 제한 화면

같은 이메일로 탈퇴 후 N일(기본 30일) 안에 다시 가입하려 할 때, 거절 대신 환영으로 시작해 언제 가입할 수 있는지 정확히 알려 주는 화면을 기존 회원가입 프로토타입에 추가한다. 응답·문구는 한국어.

## 요구사항 체크

1. 탈퇴 후 N일 이내 재가입 불가.
2. 같은 이메일로 시도하면 탈퇴한 날짜를 밝히고 1번을 안내.
3. 다시 가입할 수 있는 날짜를 명시.
4. "다시 돌아오셨군요!" 류의 인사로 시작.

가입 가능일 = 탈퇴일 + N일(예: 10월 22일 탈퇴 → 11월 21일부터). 이 해석을 노트에 적는다.

## 화면 구성 (위에서 아래로)

1. 마스코트 + h1 "다시 돌아오셨군요!" + 부제 "<서비스>를 다시 찾아 주셔서 반가워요."
2. 본문: "**<이메일>** 계정은 **YYYY년 M월 D일 (요일)**에 탈퇴했어요. 탈퇴 후 N일 동안은 같은 이메일로 다시 가입할 수 없어요."
3. 정보 표: 탈퇴한 날 / 다시 가입할 수 있는 날(포인트 컬러로 강조) / 남은 기간 "18일 (D-18)".
4. 진행 막대: 탈퇴일 → 가입 가능일 경과 비율, 양끝 "탈퇴 10.22" "가입 가능 11.21".
5. 짧은 이유 한 줄(예: 주문·혜택 기록을 정리하는 기간) + 다른 이메일로 바로 가입 가능 안내.
6. 버튼: 주 버튼 "다른 이메일로 가입하기"(이메일 비우고 가입 2단계로, 1단계 미완료면 1단계로), "가입 가능일에 알림 받기"(토스트로 날짜·이메일 확인), "홈으로".

## 진입 지점 (오류 예방)

- 가입 2단계 이메일 확인: 중복 확인 결과에 `withdrawn` 상태 추가 → 칸 아래 "탈퇴 후 N일이 지나지 않은 이메일이에요. [재가입 안내 보기]", 다음 버튼을 누르면 재가입 화면으로.
- 로그인 이메일 단계: 제한 중이면 바로 재가입 화면, 기간이 지난 탈퇴 계정이면 "탈퇴한 계정이에요. [이 이메일로 다시 가입하기]".
- 기간이 지난 이메일로 가입 2단계에 오면 "다시 돌아오셨군요! 예전 계정은 ○월 ○일에 탈퇴했어요. 같은 이메일로 바로 다시 가입할 수 있어요." 배너.

## 구현 메모

- 데모 데이터는 "며칠 전 탈퇴"로 저장하고 오늘 기준으로 계산해 언제 열어도 맞게: `WITHDRAWN={'bye@hj.com':12,'old@hj.com':45}`.
- 날짜는 로컬 자정 기준(`setHours(0,0,0,0)`), 표기는 `YYYY년 M월 D일 (요일)`, 막대 끝은 `M.D`.
- 화면을 `SCREENS`에 추가하고, 해시로 직접 들어왔는데 상태가 없으면 홈으로 보낸다.
- UX 노트에 다음 번호로 카드 6개: 감정적 디자인·피크엔드(인사), 시스템 상태 가시성(날짜·D-day), 맥락 일치·인식>기억(이메일·탈퇴일 표기), 오류 복구(다른 이메일), 사용자 통제(알림·홈), 오류 예방(입력 단계에서 감지). 화면 바로가기에서는 제한 계정 예시로 연다.
- 데모 안내에 체험 이메일 두 개를 적는다.
- playwright로 세 경로(가입 2단계 제출, 로그인, 기간 지난 이메일 배너)를 확인한다.
