# HJ전자 회원가입 UX 개선 프로토타입

애플 공식 스토어의 회원가입 흐름을 분석해, UX 원칙을 어긴 지점을 보완한 가상의 휴대폰 회사 **HJ전자** 회원가입 프로토타입입니다.

## 보기

- `index.html`을 브라우저로 열면 바로 동작합니다 (외부 의존성은 Google Fonts뿐).
- GitHub Pages: 저장소 Settings → Pages → Branch `main` / `/ (root)` 저장 후 `https://tpfls4747.github.io/apple-sing-up/`

## 흐름

스토어 메인 → 계정 메뉴 → 로그인 → 가입 1단계(기본 정보) → 2단계(이메일·암호) → 3단계(약관) → 4단계(이메일 인증) → 가입 완료

화면 오른쪽 **UX 노트**와 [UX 개선 노트 문서](UX-improvement-notes.md)에서 화면별 "기존 문제 → 개선 → 적용 원칙"을 볼 수 있습니다.

| 구간 | 애플의 문제 | HJ전자의 개선 | 원칙 |
|---|---|---|---|
| 진입 | 계정 메뉴가 장바구니 안에 숨어 있음 | 우측 상단 "로그인 / 회원가입" 노출, 장바구니와 분리 | 제이콥의 법칙, 멘탈 모델 |
| 로그인 | 가입 링크가 작은 텍스트 + 외부 이동 | "새 계정 만들기"를 같은 크기 버튼으로, 미가입 이메일은 바로 가입 연결 | 시각적 위계, 피츠의 법칙, 오류 복구 |
| 계정 생성 | 다른 사이트로 이동, 긴 단일 폼, 생년월일 드롭다운 3개 | 헤더 유지, 4단계 진행 막대, 생년월일 한 칸 입력 | 일관성, 점진적 공개, 효율성 |
| 암호 | 툴팁이 입력칸을 가림, 조건 충족해도 90% | 조건을 필드 아래 고정, 3개로 축소, 말로 된 강도 표시 | 시스템 상태 가시성, 인지 부하 |
| 오류 | 손대지 않은 칸에 엉뚱한 오류 | 입력한 칸만 검사, 칸에 맞는 문구 | 오류 예방, 오류 복구 |
| 약관 | 전체 동의 없음, 필수/선택 구분 불명확 | 전체 동의, [필수]/[선택] 그룹, 누락 항목 표시 | 제이콥의 법칙, 그룹화 |

## 체험 팁

- 이메일 인증 코드는 아무 숫자 6자리나 통과합니다.
- `hj@hj.com`을 입력하면 "이미 가입된 이메일" 오류를 볼 수 있습니다.
- 로그인 화면에 가입되지 않은 이메일을 넣으면 그 이메일로 가입을 이어 줍니다.

## 파일

- `index.html` — 프로토타입 (로고·마스코트 내장)
- `UX-improvement-notes.md` — 화면별 UX 개선 노트 (기존 문제 → 개선 → 적용 원칙, 원칙 색인)
- `assets/logo-mark.svg`, `assets/logo-lockup.svg` — 빨간 토끼 로고
- `assets/mascot.png` — 마스코트 원본(배경 투명)
