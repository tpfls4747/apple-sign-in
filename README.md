# HJ전자 회원가입 UX 개선 프로토타입

애플 공식 스토어의 회원가입 흐름을 분석해, UX 원칙을 어긴 지점을 보완한 가상의 휴대폰 회사 **HJ전자** 회원가입 프로토타입입니다. 화면 구성과 인터랙션은 애플 스토어를 따르고, 포인트 컬러(빨강)와 토끼 로고는 HJ전자 것을 그대로 씁니다.

## 보기

- `index.html`을 브라우저로 열면 바로 동작합니다 (외부 의존성은 Google Fonts뿐).
- GitHub Pages: 저장소 Settings → Pages → Branch `main` / `/ (root)` 저장 후 `https://tpfls4747.github.io/apple-sign-up/`

## 흐름

스토어 메인 → 계정 메뉴 → 로그인(이메일 → 암호/패스키) → 가입 1단계(기본 정보) → 2단계(이메일·암호) → 3단계(약관) → 4단계(이메일 인증) → 가입 완료. 로그인 화면에서 "암호를 잊으셨나요?"로 암호 재설정 화면에 갈 수 있습니다.

탈퇴 후 재가입: 탈퇴한 지 30일이 안 된 이메일로 가입하거나 로그인하면 "다시 돌아오셨군요!" 재가입 안내 화면으로 이어집니다. 탈퇴일, 다시 가입할 수 있는 날, 남은 기간을 보여 주고 다른 이메일로 바로 가입할 수 있게 합니다. (이 기능은 화면 시연용으로, `bye@hj.com`·`old@hj.com` 두 체험 계정에만 동작합니다. 실제 탈퇴 이력은 서버에 저장하지 않습니다.)

별도 페이지 [UX 개선 노트](ux-notes.html)(푸터에서도 열림)와 [UX 개선 노트 문서](UX-improvement-notes.md)에서 화면별 "기존 문제 → 개선 → 적용 원칙"을 볼 수 있습니다.

| 구간 | 애플의 문제 | HJ전자의 개선 | 원칙 |
|---|---|---|---|
| 진입 | 계정 메뉴가 장바구니 안에 숨어 있음 | 우측 상단 "로그인 / 회원가입" 노출, 장바구니와 분리 | 제이콥의 법칙, 멘탈 모델 |
| 로그인 | 가입 링크가 작은 텍스트 + 외부 이동 | "새 계정 만들기"를 같은 크기 버튼으로, 미가입 이메일은 바로 가입 연결, 이메일 → 암호 2단계와 패스키 | 시각적 위계, 피츠의 법칙, 오류 복구 |
| 계정 생성 | 다른 사이트로 이동, 긴 단일 폼, 생년월일 드롭다운 3개 | 헤더 유지, 4단계 진행 막대, 성/이름 분리, 생년월일 한 칸 입력, 떠 있는 라벨 | 일관성, 점진적 공개, 효율성 |

| 오류 | 손대지 않은 칸에 엉뚱한 오류 | 입력한 칸만 검사, 칸에 맞는 문구 | 오류 예방, 오류 복구 |
| 약관 | 전체 동의 없음, 필수/선택 구분 불명확 | 전체 동의, [필수]/[선택] 그룹, 누락 항목 표시 | 제이콥의 법칙, 그룹화 |
| 인증 | — | 이메일 6자리 코드, 자동 확인, 5회 제한, 재전송 60초 간격·3회 | 효율성, 오류 예방 |
| 진행 유지 | 새로고침하면 처음부터 | 단계별 주소, 뒤로 가기 지원, 입력 보존(암호 제외) | 사용자 통제 |
| 보안 안내 | 비밀번호가 어떻게 보호되는지 알 수 없음 | 비밀번호 칸 아래·가입 완료 버튼 아래 암호화 배지, 완료 요약에 보관 상태 | 시스템 상태 가시성 |

| 재가입 제한 | — | "다시 돌아오셨군요!" 인사, 탈퇴일·가입 가능일·남은 기간 표시, 다른 이메일로 가입 | 감정적 디자인, 시스템 상태 가시성, 오류 복구 |

## 체험 팁

- 이제 **실제 Supabase**에 연결되어 있습니다. 가입하면 실제 계정이 만들어지고 인증 코드 메일이 발송됩니다. 설정 방법은 [supabase/README.md](supabase/README.md)를 보세요.
- 이메일 인증 코드는 메일로 온 6자리입니다. 틀리면 남은 횟수가 나오고 5번 틀리면 잠깁니다. 재전송은 60초 간격, 최대 3회입니다.
- 이미 가입한 이메일은 2단계에서 "다음"을 누르면 "이미 가입된 이메일이에요"가 바로 나옵니다(약관·코드 단계로 가기 전). 이 확인은 `supabase/schema.sql`의 `email_is_registered` 함수가 있어야 하고, 없으면 막지 않고 넘어가 4단계에서 알려 줍니다.
- 로그인에 실패하면 이메일이 틀렸는지 암호가 틀렸는지 알려 주지 않고 같은 문구를 보여 줍니다.
- 암호 재설정은 메일로 받은 6자리 코드와 새 암호를 입력하면 바뀌고, 바로 로그인됩니다.
- `bye@hj.com`은 12일 전 탈퇴한 계정(재가입 제한 화면), `old@hj.com`은 45일 전 탈퇴한 계정(환영 배너와 함께 바로 재가입)으로 동작합니다. 서버와 무관한 화면 시연용입니다.
- `password1`, 이메일·이름이 들어간 암호를 입력하면 암호 차단 문구를 볼 수 있습니다.
- 가입 중 새로고침해도 입력이 남습니다(탭을 닫으면 삭제). 보안상 암호는 저장하지 않아 2단계로 돌아갑니다.
- `ux-notes.html`의 "이 화면 보기" 링크(`?demo`)는 서버에 연결하지 않고 화면만 보여 줍니다. 이때 인증 코드는 `123456`입니다.
- 패스키 로그인, 로그인 유지 체크박스, 소셜 로그인은 아직 지원하지 않습니다.
